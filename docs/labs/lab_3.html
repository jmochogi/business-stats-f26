Lab 3: Data Visualization with ggplot2

Lab 3

Introduction

In this lab, we introduce a popular package called ggplot2 used for data visualization. This package is contained within the tidyverse package (already installed) so we do not need to install it separately. The term ggplot stands for “Grammar of Graphics Plot” which is a system for declaratively creating graphics. It provides a programmatic interface for specifying what variables to plot, how they are displayed, and general visual properties. The package allows users to create a wide variety of high-quality and customizable statistical graphs, making it a valuable tool for exploratory data analysis and presentation.

Data Visualization for numerical Variables

Single Numerical Variable

In Lab 2, we computed numerical summary statistics such as mean, median, quartiles, etc. for the numerical variable price from the duke_forest dataset. Recall that we used both base R and the Tidyverse approaches to compute the statistics.

In this lab, we use the ggplot2 package to create various visualizations for the price variable.

Dot Plot

There are three basic steps for creating a visualization using functions from the ggplot2 package.

Below are the steps as applied for the dot plot. The function is called ggplot() and can be applied in the following steps to create a dot plot:

  • Step 1: Add the data argument and set the value to the data set name (in this case duke_forest). Use the code below:
Code
ggplot(data = duke_forest)
  • Step 2: Next, add variables using the mapping argument and the sub function aes (aesthetics). This step defines how variables should be mapped on the axes. Since we are dealing with one variable (price), we will just use the \(x-axis\). Notice that we begin the mapping on a new line to separate it from the data argument. This makes the code easier to read.
Code
ggplot(data = duke_forest, 
       mapping = aes(x = price))
  • Step 3: Set the visual properties by adding the geom_dotplot() function. Recall that functions must have a parenthesis at the end even if you don’t add any arguments in them. See code below:
Code
ggplot(data = duke_forest, 
       mapping = aes(x = price))+ 
       geom_dotplot()
Bin width defaults to 1/30 of the range of the data. Pick better value with
`binwidth`.

Histogram

Another tool we can use to visualize the distribution of a single numerical variable is a histogram. To create a histogram for the price variable, we follow the exact same steps as above but only change the geom_dotplot part to geom_histogram. Notice also that you can do all the three steps in one step as shown below:

Code
ggplot(data=duke_forest, 
       mapping = aes(x = price)) +
       geom_histogram()
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.

Boxplot

We can also create a boxplot in the same way but change the geometry to geom_boxplot. See below:

Code
ggplot(data = duke_forest, 
       mapping = aes(x=price)) + 
       geom_boxplot()

  • In Lab 2, we computed the mean as one of the numerical summary statistics for the price. Do you think the mean is a good measure of the typical house price in Duke Forest? Why or why not?

Two Numerical Variables

Scatter Plots

A scatter plot is the most commonly used visualization tool for examining association between two numerical variables. To create a scatter plot using the ggplot2() function, you have to specify the variable on the \(x-axis\) and the one on the \(y-axis\). In addition, you will use geom_point() to set the dots, but these can be changed using further arguments.

Below is the code for creating a scatter plot for the variables price and area. from the duke_forest dataset.

Code
ggplot(data = duke_forest, 
       mapping = aes(x = area, y = price)) + 
       geom_point()

Question - What pattern do you notice from the above scatter plot? Is this what you expected?

You can add some layer of complexity to the scatter plot to allow you compare three variables. For example, you may want to compare the relationship between price and area by cooling. To do this, you use the color argument inside the aes() function as shown below. Notice that a legend pops up automatically to tell the reader what each color represents.

Code
ggplot(data = duke_forest, 
       mapping = aes(x=area, y = price, color = cooling))+ 
       geom_point()

Question - What insights do you get from this new scatter plot?

Data Visualization for Categorical Variables

Single Categorical Variable

You can visualize a single categorical variable using tools such as simple bar plots and pie charts. For this section, we will use the loan50 data set which contains 50 observations of 10 variables related to loans. You can use the help query ?loan50 to pull the documentation for this data set.

Simple Bar Plot

One of the categorical variables in the loan50 data set is loan_purpose (e.g., car, debt consolidation, etc.). Suppose we want to visualize the distribution of the loan_purpose variable. We follow the same steps as for creating a dot plot, but change the geometry to geom_bar(). See code below:

Code
ggplot(data = loan50, 
       mapping = aes(x = loan_purpose)) + 
       geom_bar()

Notice that the horizontal scale labels overlap each other. One way to fix this is to place the loan_purpose variable on the y-axis as shown below:

Code
ggplot(data = loan50, 
       mapping = aes(y = loan_purpose))+ 
       geom_bar()

This bar plot shows that most loans were taken for debt consolidation while small business and renewable energy had among the least frequency.

In case you want to color the bars, you can use the fill argument inside the aes function as shown below:

Code
ggplot(data = loan50, 
       mapping = aes(y = loan_purpose, fill=loan_purpose)) + 
       geom_bar()

Two Categorical Variables

Another variable in the loan50 data set is loan_status. The variable which tells us whether a loan is fully paid or current. We can visualize the two categorical variable using a stacked bar plot or a side-by-side bar plot. To do this, we can fill the loan_purpose bars with the loan_status as shown below:

Code
ggplot(data=loan50, 
       mapping = aes(y = loan_purpose, fill = loan_status)
       ) +
       geom_bar()

It can be difficult to discern the quantities from the stacked bar plot. A side-by-side (or dodged) bar plot can be a better option here. You can use the position argument inside the geom_bar() function as shown below:

Code
ggplot(data = loan50, 
       mapping = aes(y = loan_purpose, fill = loan_status)
       ) +
       geom_bar(position = "dodge")

Visualizing a Numerical variable by Category

In some cases, you may want to visualize the distribution of a numerical variable across levels of a categorical variable. For example, suppose we want to see the distribution of price of homes based on type of heating. We can achieve this using side-by-side box plots as shown below:

Code
ggplot(data = duke_forest, 
       mapping = aes(x = cooling, y = price)
       ) +
       geom_boxplot()

Again, you can color the box plots by cooling, or any other categorical variable. See code below that colors the box plots by cooling:

Code
ggplot(data = duke_forest, 
       mapping = aes(x = cooling, y = price, fill = cooling)
       ) +
       geom_boxplot()
